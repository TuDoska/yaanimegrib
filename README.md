# 🍄 YaAnimeGrib

Аніме-сервіс: розклад серій із живими таймерами, каталог, відгуки, спільний перегляд YouTube-відео з друзями і модерація. Інтерфейс трьома мовами: українською, англійською та російською.

> YaAnimeGrib не зберігає й не розповсюджує серії. Дані про аніме надходять з [AniList](https://anilist.co). На сторінці кожного аніме є посилання на офіційні платформи, де його можна дивитися легально. Кімнати працюють лише з YouTube-відео (офіційні трейлери та канали правовласників).

## Можливості

- **Таймери нових серій**: на головній, у розкладі та на сторінці аніме. Відлік оновлюється щосекунди.
- **Автооновлення серій**: щойно серія виходить, сайт сам підтягує свіжі дані.
- **Розклад на тиждень** у часовому поясі глядача.
- **Каталог**: пошук, жанри, тип, статус, сортування, «Показати ще».
- **Де дивитися легально**: офіційні стрімінги з AniList.
- **Кімнати спільного перегляду** (Socket.io + YouTube IFrame API):
  - синхронні play, пауза й перемотка;
  - чат, список глядачів;
  - режим «керує лише власник», зміна відео;
  - вилучення глядачів, видалення повідомлень, скарги.
- **Акаунти**: реєстрація й вхід (bcrypt + JWT у httpOnly cookie), обране на сервері. Гостьове обране переноситься після входу.
- **Відгуки й оцінки**: один відгук на аніме, середня оцінка глядачів сайту.
- **Модерація**:
  - ролі «глядач», «модератор», «адмін»;
  - скарги на відгуки, повідомлення та кімнати;
  - приховування й видалення;
  - бан із причиною, статистика.
- **Безпека**: Helmet (CSP), rate limit, перевірка Origin, валідація вводу, екранування HTML.

## Технології

Node.js, Express, Socket.io, MongoDB (Atlas) / NeDB, Vanilla JS, CSS Grid і Flexbox, AniList GraphQL API.

## Локальний запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # інтеграційні тести API та сокетів
```

Без `MONGODB_URI` дані зберігаються у файлах у папці `data/`. Перший зареєстрований користувач автоматично стає адміністратором.

## Публікація в інтернеті (безкоштовно)

1. **MongoDB Atlas** (mongodb.com/atlas): створи безкоштовний кластер M0 і користувача бази. У Network Access додай `0.0.0.0/0`, потім скопіюй рядок підключення `mongodb+srv://…`.
2. **Render** (render.com): увійди через GitHub, вибери **New → Blueprint** і цей репозиторій. Файл `render.yaml` налаштує все сам.
3. На Render задай змінні:
   - `MONGODB_URI` — рядок з Atlas;
   - `ADMIN_USERNAME` — твій нік, щоб стати адміном.
4. Сайт буде доступний на адресі `https://yaanimegrib.onrender.com` (або схожій). На безкоштовному тарифі сервер «засинає» без відвідувачів, і перше відкриття займає близько 30–50 секунд.

## Структура

```
server/
  index.js        — Express, Helmet, маршрути, статика
  db.js           — MongoDB або NeDB з однаковим API
  auth.js         — JWT, ролі, middleware
  sockets.js      — кімнати: синхронізація, чат, кік
  routes/         — auth, favorites, reviews, reports, rooms, admin
public/
  *.html          — сторінки
  css/style.css
  js/i18n.js      — переклади UA / EN / RU
  js/anilist.js   — запити до AniList (кеш, черга, повтори)
  js/ui.js        — шапка, обране, картки, таймери, скарги
  js/*.js         — логіка окремих сторінок
test/api.test.js
```
